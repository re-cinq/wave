## Gap Detail

### 1. Work Board (`/work`) — Missing filterbar + actions

**Mockup (02-work-board.html):**
- `<div class="filterbar">` with 4 `<select>` elements (forge, kind, state, label) + search input
- "Refresh" + "New work" buttons in page-header
- Work item list rows with: icon, title+badge, meta (forge, author, tags), kind badge, status badge, action button
- Pagination: "6 of 23 items shown · load more"

**Actual (`/work`):**
- No filterbar
- No "Refresh" or "New work" buttons
- Shows bindings table, not work items
- No pagination

**Gap:** filterbar, action buttons, work item list (bindings list ≠ work items)

---

### 2. Work Item Detail (`/work/:forge/:repo/:num`) — Disabled dispatch + missing binding picker

**Mockup (03-work-item.html):**
- Breadcrumb: Work › forge/repo › issue #N
- Issue body in `.card`
- Binding picker radio list (impl-issue, research, scope with cost/time estimates)
- `<details>` with custom pipeline/adapter/model/budget/detached/notes options
- "Run impl-issue" + "Dry-run" buttons
- Recent runs list
- Aside: Item dl, Suggested binding card, Live cost forecast card

**Actual:**
- "Run on this issue" button disabled (shows "disabled — wires up in #2.4")
- No binding picker UI
- No cost forecast card
- No recent runs section
- Hint: "Could not fetch live details"

**Gap:** Dispatch wiring (#2.4), binding picker, cost forecast, recent runs

### 3. Evolution Proposal Detail (`/proposals/:id`) — No action UI

- Replay forecast signal-list
- Aside: trigger signals grid, version dl, generated by dl, related proposals

**Actual (`/proposals/detail.html`):**

- No approve/reject buttons

- No tabs

- No replay forecast

**Gap:** Full proposal action UI — per epic, this is Phase 3.4 work (`/proposals` approve/reject + CLI)
